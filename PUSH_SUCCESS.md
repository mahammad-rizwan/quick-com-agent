## 🎓 What Your Friend Needs to Do

### **Step 1: Clone Repository**
```bash
git clone https://github.com/mahammad-rizwan/quick-com-agent.git
cd quick-com-agent
```

### **Step 2: Install Dependencies**
```bash
# Node.js
cd backend
npm install

# Browsers
npx playwright install chromium
cd ../blinkit-mcp
uv run python -m playwright install firefox
```

### **Step 3: Configure**
```bash
# Create .env file
cd ../backend
cp .env.sample .env
# Edit .env and add their Groq API key
```

### **Step 4: Login to Instamart**
```bash
node loginInstamart.js
# Follow prompts
```

### **Step 5: Start Server**
```bash
node server.js
```
